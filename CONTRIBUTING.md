# Contributing

Thank you for helping improve WinMTR. Use a category prefix at the start of every commit subject and pull request title, followed by a short description:

```text
[prefix]: <short description>
```

Choose one of these prefixes:

| Prefix | Use for |
| --- | --- |
| `[fix]` | Bugfixes |
| `[feat]` | Features |
| `[build]` | Build changes |
| `[chore]` | Chores |
| `[ci]` | Continuous integration changes |
| `[docs]` | Documentation |
| `[style]` | Style changes |
| `[ref]` | Refactoring |
| `[perf]` | Performance improvements |
| `[test]` | Tests |

For example: `[fix]: handle unreachable hosts`.
